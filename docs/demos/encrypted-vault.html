🔒 neuron-db · SecureNeuronDB — encrypted vault

AES-256-GCM · key never stored

① store a secret

Values are encrypted with AES-256-GCM under a key derived from your passphrase (PBKDF2). The passphrase is supplied per call and never written to disk. The cue is indexed by a keyed hash, so even the lookup key is opaque.
This is the realistic threat model: an attacker who steals the .db file sees only the ciphertext below. Lose the passphrase, lose the data — that's the point.
