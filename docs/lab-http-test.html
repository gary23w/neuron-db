neuron-db WASM — making a real web call

Proof that wasm32-unknown-unknown can reach the network in a browser: the WASM declares a host_http import, the page provides it with fetch, and the WASM owns the request — it calls out, the host runs the socket, the body comes back into wasm memory via http_deliver, and neuron-db stores it. The call goes straight to a public CORS API (Wikipedia), no worker, no proxy.
