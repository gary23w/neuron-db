IN YOUR BROWSER · NO SERVER · NO KEY The hippocampus & the neocortex, both client-side. what is this?

neuron-db is the memory — the real Rust core compiled to a ~1.4 MB WebAssembly module, running locally. Every message you send is stored and recalled by it; watch the neurons fire on the right. The optional local Llama (via WebLLM, WebGPU) is the voice on top — it never sees your whole history, only what the memory recalls. Paste something bigger than the model's context window and neuron-db simply absorbs it into memory — the model still answers from recall. That's the whole point. Memory works on any device; the model needs a WebGPU browser (desktop Chrome/Edge).
