The hippocampus and the neocortex, both client-side.

neuron-db is the memory — the real Rust core compiled to a ~1.4 MB WebAssembly module, running locally. Every message you send is stored and recalled by it; watch the neurons fire on the right. The optional local Llama (via WebLLM, WebGPU) is the voice on top — it never sees your whole history, only what the memory recalls. Memory works on any device; the model needs a WebGPU browser (desktop Chrome/Edge).
