IN YOUR BROWSER · NO SERVER · NO KEY The hippocampus & the neocortex, both client-side. what is this?

neuron-db is the memory — the real Rust core compiled to a ~1.5 MB WebAssembly module, running locally. Every message you send is stored and recalled by it; watch the neurons fire on the right. The optional local Llama (via WebLLM, WebGPU) is the voice on top — it never sees your whole history, only what the memory recalls. Paste something bigger than the model's context window and neuron-db simply absorbs it into memory — the model still answers from recall. That's the whole point. Memory works on any device; the model needs a WebGPU browser (desktop Chrome/Edge).

The memory does the retrieving so the tiny model only has to narrate: it routes each question to the right document, recalls by meaning and association, and for a “walk me through…” question hands back an ordered span so even a 1B model recounts a chain in sequence instead of confabulating. It also has feelings: give it a mood (“be playful”) or an opinion (“you love rust”, repeat to deepen it) and that affect — a transient mood plus durable, accumulating stances — colors how it talks. Watch the mood and opinion chips on the right.
